## 📱 About the Project

In *Dragon Ball Legends*, QR Code events are historically frustrating for the community because friend codes **expire within a few minutes** due to built-in security timestamps. Players are often forced to constantly take screenshots, crop them, and spam them in Discord servers or Reddit threads.

This tool solves that problem by allowing players to generate fresh, scannable QR Codes instantly from any device, making the daily summon grind much smoother.

### Key Features:
*   **Instant Generation:** Input the required friend code data and get a clean, high-quality QR Code immediately.
*   **Mobile-First Design:** Optimized for smartphones so players can scan codes directly from a PC screen or share them via mobile apps.
*   **100% Client-Side:** Lightweight and fast, built entirely with static web technologies and hosted for free on GitHub Pages.

---

## 🛠️ Tech Stack

*   **HTML5 & CSS3** - Responsive layout and clean UI styled for mobile and desktop screens.
*   **JavaScript (Vanilla)** - Handles the logic and dynamic data input.
*   **QRCode.js** (or your specific library) - Client-side QR Code generation library.
